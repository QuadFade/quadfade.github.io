# QuadFade Text-Based Browser RPG

A mobile-first, text-based browser RPG built for GitHub Pages. The interface uses a top-left hamburger menu that opens a 2-column panel of 9 fantasy-themed buttons for quick navigation.

Pages:
- Inventory, Character, Stats, Skills, Professions, Settings, Quests, Achievements, Codex

Notes:
- Mobile-first and touch-optimized. Emoji placeholders are used for icons; swap with SVGs for polish.
- No secrets or personal data are included.

How to preview:
1. Serve this folder as a static site (or push to gh-pages).  
2. Open index.html in a browser.

Contributions welcome — open an issue or PR with improvements.
